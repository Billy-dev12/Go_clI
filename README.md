# 🚀 Bill CLI (Billahi Robby CLI)

Asisten CLI terkeren untuk developer Laravel dan otomasi workflow.

## ✨ Fitur Utama
- **Laravel Automation**: `buat`, `cek`, `setup lingkungan`, `setup project (clone)`, `ser` (serve), dan `cleanup`.
- **GitHub Integration**: `push` mudah tanpa ribet.
- **System Tools**: Mode interaktif (REPL) dan instalasi otomatis ke PATH.
- **Auto-Release**: Binari selalu up-to-date via GitHub Actions.

## 📥 Cara Instalasi (Instan)

Sekarang kamu bisa install langsung via terminal tanpa perlu download manual atau clone repo!

### 🐧 Linux / macOS
Buka terminal dan jalankan:
```bash
curl -fsSL https://raw.githubusercontent.com/Billy-dev12/Go_clI/main/install.sh | bash
```

### 🪟 Windows (PowerShell)
Buka PowerShell dan jalankan:
```powershell
irm 'https://raw.githubusercontent.com/Billy-dev12/Go_clI/main/install.ps1' | iex
```
